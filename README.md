# Последние Врата — сборка APK

В папке `www` лежит вся игра одним файлом `index.html`. Остальное — обёртка Capacitor, которая превращает её в Android-приложение.

## Сборка на GitHub без Android Studio

В проекте есть файл `.github/workflows/build-apk.yml`. Если положить проект в репозиторий на GitHub,
сборка запустится сама при каждой отправке в ветку `main`. Её также можно запустить вручную:
вкладка Actions → Build APK → Run workflow.

Когда сборка закончится, откройте её на вкладке Actions и скачайте файл из раздела Artifacts:
внутри архива `last-gates-apk` лежит `app-debug.apk`.

Горизонтальный экран в этой сборке закрепляется автоматически.

## Сборка на своём компьютере

Что нужно установить:

1. Node.js (версия 22 или новее) — https://nodejs.org
2. Android Studio — https://developer.android.com/studio

## Сборка

Откройте терминал в этой папке и выполните по очереди:

```
npm install
npx cap add android
npx cap sync android
npx cap open android
```

Последняя команда откроет проект в Android Studio. Дождитесь, пока он загрузится, затем в меню выберите
Build → Build Bundle(s) / APK(s) → Build APK(s).

Готовый файл появится здесь:
`android/app/build/outputs/apk/debug/app-debug.apk`

Скопируйте его на телефон и установите (понадобится разрешить установку из неизвестных источников).

## Горизонтальный экран

Игра рассчитана на горизонтальный экран. Чтобы приложение не переворачивалось, после `npx cap add android`
откройте файл `android/app/src/main/AndroidManifest.xml`, найдите тег `<activity` и добавьте в него строку:

```
android:screenOrientation="sensorLandscape"
```

## Обновление игры

Когда появится новая версия, замените `www/index.html` новым файлом и выполните:

```
npx cap sync android
```

Затем снова соберите APK в Android Studio.

## Сохранения

В приложении прогресс хранится в памяти самого приложения и не пропадает при очистке браузера.
Перенести героя из браузерной версии можно кодом: Оплот → Настройки → «Код героя».
